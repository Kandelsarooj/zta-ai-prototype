About This Prototype

This system was designed and built as part of an MSc Software Engineering dissertation at the University of West London. It demonstrates the combined operation of Zero Trust Architecture (ZTA) and Artificial Intelligence (AI)-based anomaly detection for cloud environment security.

Dissertation Details
Title: Cybersecurity Challenges in Cloud Computing: A Strategic Analysis of Zero Trust Architecture and AI-Based Threat Detection Mechanism
Author: Saroj Kandel (Student ID: 34114665)
Programme: MSc Software Engineering
Institution: University of West London
Module: Research Methods (CP70011E)
Research Question: How effectively can ZTA and AI-based threat detection address cloud cybersecurity challenges?

System files explained
app.pyMain Flask application — connects all components, handles routing between pages, manages Flask sessions, processes API requests
zta.pyZero Trust Architecture engine — implements 4 sequential checks (identity, role, device, location) based on NIST SP 800-207 framework
ai_detector.pyAI anomaly detector — Isolation Forest trained on 20 normal login patterns, analyses 5 behavioural features, returns risk score 0–100
database.pySQLite database manager — creates tables, saves every login attempt, retrieves logs for dashboard, exports CSV for dissertation data
templates/HTML pages — home, zta_check, ai_analysis, step_up, decision, results, about — all using base.html template inheritance
Attack scenarios and expected outcomes
✅
Normal Login — alice / managed_laptop / London / 10am
All 4 ZTA checks pass. AI score low (approx 39). Full access granted. Demonstrates system correctly identifies legitimate users without false positives.
💥
Brute Force — attacker / unknown_vm / Unknown / 3am / 15 attempts / 1s speed
ZTA fails at identity check (wrong password). AI score 100. Denied immediately. Demonstrates ZTA blocks attacks before AI even runs.
😈
Insider Threat — bob / managed_laptop / London / 2am
ZTA passes (legitimate credentials). AI score medium (~65) due to unusual hour. Step-up authentication triggered. If passed: limited read-only access. Demonstrates AI catches what ZTA cannot.
➡️
Lateral Movement — dave / managed_laptop / London / 8 attempts / 5s speed
ZTA passes. AI score high (~76) due to rapid repeated attempts. Denied by AI. Demonstrates AI detecting automated attack patterns from authenticated user.
⚠️
Zero-Day — unknown_user / unregistered_device / Tor Exit Node / 20 attempts
ZTA fails immediately (unknown user). AI score 100. Double denial. Demonstrates system resilience against completely novel attack patterns.
